# CnGal 新站前端编码规范

适用 MainSite、MainSite.Shared、SDK.MainSite、SDK.MainSite.AspNet；架构与发布细节参见 [重构指导](MainSiteFrontendRefactorGuide.md)。本规范不要求改动现有后端契约、URL 或视觉设计。

## 1. 分层和数据所有权

- MainSite 负责宿主；Shared 负责页面、组件和编辑会话；SDK 负责 API、映射、聚合、缓存与错误；AspNet 负责身份及宿主适配。
- Shared 不直接请求业务 HTTP 接口。浏览器第三方编辑器的已有图片直传保持原协议，不在浏览器暴露宿主访问令牌。
- 展示组件只接收数据；业务根拥有请求、提交与刷新；本地交互不经 SignalR 传递逐帧操作。
- 默认静态 SSR。App、Routes 和布局不整体启用交互；渲染模式仅放在页面或明确的业务根。搜索保持 GET 表单和 URL 筛选。
- 不新增通用状态管理框架、页面基类、反射映射或新的客户端项目。

## 2. 浏览器模块

- 专用实现放同目录 .razor.js；共享代码只保留真正公用的生命周期、dialog、资源下载和全站行为。
- 自动挂载组件使用 Light DOM Custom Elements 和 mount(root, { signal }) 契约；参数由 Blazor 同步的组件使用实例工厂。二者不能重复控制同一实例。
- 异步初始化检查连接代次和取消。update 必须幂等；dispose 必须幂等并清理监听、观察器、计时任务、动画和对象 URL。
- 普通事件委托到实例根，读取当前节点并排除嵌套实例。纯按钮使用 data-cg-action，全站入口仅安装一次。
- 禁止全局组件扫描、全局 MutationObserver、DOM 快照比对、初始化属性标记以及移动 Razor 节点到 body。必要观察只针对拥有的局部内容，并过滤自身写入。
- 节点未齐全时允许后续更新；不等待图片下载、不通过固定延迟或轮询决定初始化成功。
- JS 模块不保存组件单例。DOM、编辑器、选择、.NET 回调和计时器必须属于实例；仅库下载 Promise 和不可变定义可以共享。
- C# 分别释放控制器与模块引用；DOM 移除时通过 cg-owned 本地清理。初始化失败记录组件/模块/阶段，并提供重试或原生降级，不吞错误。
- 仅在释放阶段忽略预期断连；业务请求取消按取消契约处理。

## 3. HTML、样式和资源

- 普通 Razor 组件不输出可执行 script、内联浏览器事件或 eval。JSON-LD 是数据脚本例外。
- App 仅保留首屏主题引导、框架启动和 import map 等根文档必需内容。
- 本地 HTML 资源通过 Assets 引用；JS 使用框架 import map 的逻辑路径。禁止手写版本时间戳、哈希或第二份资源映射。
- Custom Elements 显式保留原元素的 display 行为；继续使用现有 design tokens、CSS 隔离、响应式布局与 CgMdiIcon 图标体系。
- 组件必须保留可访问名称、键盘操作及可用的原生链接。动画尊重 prefers-reduced-motion。
- 原生 dialog 统一管理顶层表现、焦点和滚动锁；业务 IsOpen 与浏览器选择状态不能各自维护一套业务开关。

## 4. SDK 和缓存

- 所有异步操作接受 CancellationToken。调用方取消传播异常，不能转换为成功空数据。
- 继续使用 SdkResult<T>；HTTP、超时、业务失败和格式失败分别表达。可选段失败不能伪装成有效空集合。
- HTTP 响应及时释放。统一序列化选项；日志不默认输出私人响应正文、访问令牌或认证票据。
- 业务 Client 只注册一遍。令牌处理器从调用方作用域取身份，不能把 Circuit 状态放入工厂池化作用域；外层释放不销毁工厂传输。
- 默认禁止重放。只读请求显式选择 AllowReplay；写操作的瞬态重试和 401 刷新重发均关闭。
- Unknown 不等于 Anonymous。公共缓存只存确认匿名的数据，API 来源进入缓存命名空间；现有审核用户缓存继续按可信身份和权限分区。
- 使用 PublicDataCache 的统一失效入口阻止旧代次回填，不再在命令中拼接关联缓存键。缓存对象按只读快照使用。
- HTML 共享只通过 PublicHtmlCachePolicy 的明确名单启用。身份、MiniMode、Set-Cookie、交互描述及错误响应不进入公共 CDN 缓存。

## 5. 页面和编辑器

- 单接口页面复用已有 Query；多接口编排放入领域聚合 Query。页面只处理路由、当前请求、加载和结果展示。
- 路由改变取消旧请求，结果回写前核对代次。取消后观察已启动任务，避免后台遗留请求。
- 展示子组件复用初始数据；业务根在操作后刷新，避免 SSR 与交互启动重复读取。
- 传入交互根的初始模型须兼容 Blazor 的参数序列化。`required` 可空成员使用 `[JsonIgnore(Condition = JsonIgnoreCondition.Never)]` 保留显式 null，避免被框架的 WhenWritingNull 省略后无法还原整个组件批次；不要全局放宽必需成员校验。
- 编辑会话按领域、按编辑根创建，不能作为整个 Circuit 的共享编辑实例。
- 草稿状态与串行操作通过 EditDraftController<TDraft> 组合复用，业务校验和写入留在领域会话；页面切换通过 EditSessionHost<TSession> 管理，避免复制整套会话生命周期。侧栏复用 CgEditSidebar 及其 CSS，图表复用 CanvasChartController 的 JS 生命周期。
- 草稿读写保留既有键与格式；读取失败不覆盖，提交失败或结果不确定不删除。
- 自动保存使用可取消串行循环，保存、提交和丢弃互斥。保存与提交前合并编辑器输入；外部重置后拒绝旧输入代次。
- 拖动、裁剪、滚动高亮及图表重绘在浏览器执行，只回传业务所需结果。
- SEO 每页一个 CgPageMeta/HeadContent 所有者，结构化数据在内部组合。主题 Cookie 为持久来源，MiniMode 保留服务端语义。

共用导航行为使用 `wwwroot/scripts/edit-nav.js`。只有存在同名 Razor 组件时才使用 `.razor.js`，避免孤立模块触发 BLAZOR106。

## 6. 本次验证与交付规则

用户明确要求本次不编写或运行测试。交付仅做源码、引用、语法和差异核对，不执行构建、测试、应用或浏览器验收；不得将这些核对表述成编译或运行通过。

评审应检查分层、渲染边界、资源路径、异步取消、实例所有权、身份缓存隔离、草稿兼容及模块失败降级。发布验收场景另见重构指导，均需在后续发布流程执行。

完整发布包含 Razor/CSS/JS/静态清单；部署使用不可变镜像标签，保留安全基线后的上一版镜像和旧指纹资源。CDN 清理及代理策略由实际部署环境落实，本次源码修改不代表已经发布。
